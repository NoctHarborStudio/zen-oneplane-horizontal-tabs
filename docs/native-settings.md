# Native Zen settings

Use built-in preferences before adding custom CSS. Open `about:config` and record the original values before changing them.

| Preference | Value | Effect |
| --- | --- | --- |
| `zen.theme.content-element-separation` | `0` (Number) | Removes the colored spacing around web content. |

This spacing change was confirmed in the original Windows Zen profile. It does not require a mod.

If using Nebula, keep `nebula-tab-loading-animation` at your preferred non-zero setting to retain its loading effect. Value `1` is Nebula's default. The General Improvements module changes the backdrop independently.

Restore each preference to its original value to undo the change.
