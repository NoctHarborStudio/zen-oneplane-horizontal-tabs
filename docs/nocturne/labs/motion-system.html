A — симметричное движение; B — мягкие границы и отложенное раскрытие содержимого; C — более раннее раскрытие и длинное замедление. Прототип использует один прогресс для геометрии, текста и тени. При смене профиля активная анимация завершается; при смене направления положение сохраняется, скорость может мгновенно измениться. Нативная геометрия, compositor и реальная работа Zen здесь не проверяются.
