# Nocturne 0.4.0 — architecture stabilization audit and pipeline

Status: active audit / proposed implementation order; no runtime change. Audit baseline: preview, 0.3.0-preview.47, e801c175eadcdd35b4d834fc791969ccdb146597. Target Zen 1.24.2b / Sine 2.3.3. One chat owns this audit; other preview workstreams remain independent. Rebase the evidence on current HEAD before each implementation batch. This document owns the cross-feature 0.4.0 stabilization sequence; detailed feature contracts remain in their existing owner documents.

## Evidence and scope

- Inventory: all 12 manifest entrypoints, 90 unique src JS/ESM/CSS fragments, 41 test files; five generated outputs (layout, chrome, overlay, library services, library). Build plan accounts for every src fragment. Shared media-service pure code is inlined into two bundles; this alone is not duplicate live state.
- First-pass source inspection: all entrypoint bodies fetched and scanned for functions, native commands, ownership globals, events and resource sites; source fragments scanned and selected critical paths read in detail; all test files inventoried and representative cases examined. Not a completed line-by-line semantic proof or native audit. Full per-function flow, CSS computed-style matrix and native API verification remain open.
- Baseline GitHub Actions Verify preview package succeeded: https://github.com/NoctHarborStudio/zen-oneplane-horizontal-tabs/actions/runs/44200260385. No fresh local build/test: container git clone failed DNS. CI is evidence for its own checkout only, not Zen or performance. No claim that all tests or all flows are correct.
- Status terminology: S = source-confirmed structure/defect; R = plausible risk, not a reproduced bug; V = verification gap; P0 = native data/lifecycle safety, P1 = critical UX/architecture, P2 = optimization/maintenance. Every item open unless separately verified. Do not treat a risk as permission to change accepted UX.

## Current execution and ownership map

Sine loads 12 independent entrypoints. Layout source is concatenated in lexical order (60 JS sections), chrome.css is concatenated from 19 sections. Independent generated Overlay, Library Services and Library use 2/5/5 source entries; one pure source is reused. Entry order is not a dependency contract.

Zen owns tabs, Workspaces, sessions, split groups, downloads, Places and native commands; mod owns only presentation and explicit mod settings. Existing owner APIs are migration bridges, not a reason to rename public identifiers during stabilization.

## 0.4.0 execution pipeline

Each phase is a gate, not a release number or progress percentage. Independent branches of analysis may proceed; implementation touching a common owner must be coordinated. Every runtime batch: HEAD check -> evidence -> source change -> build -> verify -> readback/CI -> native acceptance where required. Preserve Sine UUID, public URLs, native data, legacy preference keys; no broad refactor + UX redesign in one batch.

| Stage | Scope and order | Exit criteria | Status |
| --- | --- | --- | --- |
| A0 — baseline and audit | Freeze source hashes, build/version/CI contract, full call/owner inventory, diagnostic schema; confirm native target/API and collect baseline traces. Reconcile NC4 with existing NC/MB/OP issues, not duplicate fixes. | Per-script owner/event/resource inventory and actual hot paths; reproducible build/test and release checks; baseline performance recorded; documentation-only CI policy resolved. | Started: first-pass inventory + risk register; deeper audit and native baseline pending. |
| A1 — lifecycle and shared core | DisposableScope; WindowContext/capabilities; process-pref/manager lease; entrypoint readiness and generation contracts; extract one responsibility at a time; layout mount rollback. | Both Sine orders, hot reload, multiwindow, failure at each acquire, stale callbacks, disable/global quit; no orphan node/effect/observer or wrong prefs. | Open |
| A2 — native workspace/data commands | Free, Hub, Trash, Home selection, projection; explicit command gate independent of motion, journal partial moves, authoritative result. | Native identity, no duplicate creation, no unintended deletion or focus loss, partial failure recovery, native external switch and private cases. | Open |
| A3 — motion transaction and startup | Ownership matrix for startup, close, workspace, address, hover and bookmarks; MB1–MB7; shared timeline and cancellation/handoff; real-slot vs proxies comparison. ## Mandatory cross-feature native scenarios (A8)

1. Cold/warm startup, 0/1/100+ tabs, slow session, existing Free/missing Free, both initial Home/page, icons, private/unsynced/projection, delayed provider; no orphan cover, no pre-Sine guarantee.
2. Startup interrupted by search, drag, resize, workspace, overlay, native close; close cancellation, second close, OS/global quit; repeated hot reload and both service orders.
3. Rapid workspace A/B/A and native external selection while search/drag/overlay active; stable Home title, icons, bookmarks and geometry; no native duplicate switch.
4. Horizontal 1/2 rows, portrait, narrow, compact/persistent, custom toolbar, fullscreen, mixed DPI, negative monitor coordinates; hit-test actual interactive and drag areas.
5. Bunny tab reorder, Split Group, detach/return/insert/external window, Escape, lost release, OS screenshot, overlapping native drag, disabled experimental snap; no edge snapping regression.
6. File drag from indicator, recent, full Library; missing/blocked/partial/cloud, external Explorer/upload, cancel, private/public, native file preservation. Trash real-card restore/delete partial failure.
7. History/Downloads shortcut opt-ins, fallback, native history-only records, pagination and deletion confirmation in disposable profile, folder consent, decoded thumbnail budget, service reload during query/drag.
8. Page load fast/slow/redirect/cancel/overlap, tab switch, move dock; Bookmark FLIP/address wave/contour in all directions, native menus/overflow; no competing CSS animation writers.
9. Focus/keyboard/Escape and reduced motion, high contrast, native permissions; compare diagnostics on/off same hardware/profile, inspect Gecko Profiler and actual presented frames when available.
10. Native migration and rollback from legacy-disabled install; exact raw/archive identity, version/updatedAt high-water, no changed Sine UUID or native profile.
